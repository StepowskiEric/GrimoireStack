# Abductive-First Debugging

Generate multiple competing hypotheses, select the one that best explains all observed symptoms — not the first plausible cause.

## Core Protocol

### Step 1: Collect All Observations

Gather primary symptom, secondary symptoms, negative symptoms (what does NOT happen), and context (recent changes, environment, timing).

**Done when:** observations are written down and include at least one negative symptom.

### Step 2: Generate Competing Hypotheses

Generate at least 3 competing hypotheses. Force creativity — stop at the first plausible cause.

For each hypothesis, list what it explains and what it does NOT explain.

**Done when:** 3+ hypotheses exist, each with explained and unexplained observations.

### Step 3: Score by Explanatory Coherence

Score each hypothesis on: coverage (% of symptoms explained), specificity, simplicity, consistency.

**Done when:** each hypothesis has a score and the highest-scoring one is selected.

### Step 4: Select Best Explanation

Select the hypothesis with the least unexplained observations and highest coherence score.

If no hypothesis scores above 0.6, gather more evidence targeting the unexplained symptoms before proceeding.

**Done when:** best hypothesis selected with rationale, or evidence-gathering plan in place.

## Failure Modes

- **First-branch lock-in:** committing to the first plausible cause without generating alternatives
- **Ignoring negative symptoms:** what does NOT happen is as important as what does
- **Confirmation bias:** seeking evidence that supports the leading hypothesis while ignoring contradictory evidence
