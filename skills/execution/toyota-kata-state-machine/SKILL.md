# Toyota Kata

**Do not optimize by intuition alone.** This skill turns Toyota Kata into an executable protocol for disciplined iteration: define the direction, understand the current condition, target the next step, remove one obstacle, and learn.

## The Move

### 1. Direction & Current Condition
Define the improvement direction and the current reality with evidence. Create a `kata-improvement-board.md`.

### 2. Target Condition
Frame the **next** meaningful condition — near-term, observable, and specific. Not the final dream state.

### 3. Obstacle Selection
Rank likely obstacles and select the **single** one that most blocks the target. Focus on one obstacle at a time.

### 4. Experiment
Design the **smallest useful move** against the obstacle. State the expected result and how you will check it *before* starting.

### 5. Learning Review
Compare expectation to reality. Did the obstacle weaken? Is the target closer? Decide: repeat, change obstacle, accept, or stop.

## Rules
- **Do** create the `kata-improvement-board.md` before meaningful execution.
- **Do** limit each experiment to one obstacle.
- **Do not** expand scope mid-run without a fresh obstacle choice.
- **Do not** jump to a grand redesign — iterate with evidence.
